### Added
- Native `zcode` provider: the ZCode desktop client's start-plan lane is now served in-process instead of proxying to a separate `zcode-bridge` on `127.0.0.1:20131`. New `internal/zcode` package carries the three pieces the gateway validates — the identity header face (`BuildLLMHeaders` / `BuildControlHeaders`, printable-ASCII gated), the 3-block identity system asset (`identity_system.json`, embedded, `BuildSystem` + per-conversation `SessionIDFor` + `metadata.user_id`), and the plan-lane transport (`SendAnthropic`: `POST /api/v1/zcode-plan/anthropic/v1/messages` with `Authorization: Bearer <plan JWT>`, **no** signing headers, transient retry with backoff, cancel deferred until the response body closes so a stream survives).
- `KnownProviders["zcode"]` (`https://zcode.z.ai/api/v1/zcode-plan/anthropic/v1/messages`, `Format: claude`, `PreserveCacheControl`) so `getProviderConfig` resolves the provider without a `baseUrl` in connection data — this is the fix for `provider "zcode" has no baseUrl in connection data and is not in KnownProviders` (HTTP 502 on every `zcode/*` request).
- `internal/proxy/executor/zcode.go`: the only caller of the plan lane. Shapes the body with `ShapePlanBody` (3-block system, `metadata.user_id`, `max_tokens` default), relays a Claude client's own wire format, and translates the Claude reply for a Chat Completions client through the shared `handleClaudeMessages*` helpers, gated on `UpstreamClaude`.
- Native quota tracking for `zcode` connections (`usage_zcode_plan.go` + `zcode.ReadQuota`): `billing/balance` read with the control header face (`X-Device-Mid` UUID — a process-stable UUID is generated when the env var is absent, because without one the gateway answers `3001` and the read silently degrades to the usage-less `current` fallback, i.e. every card reads `used:0 remaining:total`) and the entitlement's own `period` surfaced per row.
- `ProviderModels["zcode"] = {glm-5.3, glm-5.3-flash}`, `RegistryAliases["zcode"] = "zcode"`, `ProviderAliases["zcode"] = "zai"` (models.dev limits), and the dashboard catalog entry (category oauth, `smart_toy`, `#3B82F6`) with `web/public/providers/zcode.png`.
